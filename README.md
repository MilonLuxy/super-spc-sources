# Super SPC Sources (SSS)
What started as a not-so-small compilation project, became a huge and passionate thing.
I love sounds, who doesn't like 'em?

From Beep Boops to memorable, iconic and elaborated sounds produced from the 90s, this repository aims to ease access from those who search for higher quality sounds from their favorite SNES games.

You can see the sources from each sound, along with other games here:
